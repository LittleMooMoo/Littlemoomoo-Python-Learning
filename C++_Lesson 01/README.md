# Littlemoomoo-Python-Learning
This personal repo is to help Littlemoomoo learn Python from beginner syntax
to robotics-focused engineering code.

The goal is not just to memorize Python. The goal is to learn how to think,
write, test, and debug code that can eventually help with quadruped robot
software: motor commands, kinematics, gait logic, control systems, algorithms,
and eventually more advanced topics like MPC and computer vision.

## Lessons

1. [Lesson 1: Python Basics and Motor Safety](01_python_basics/lesson_01_motor_safety.md)
2. [Python Concept Map Script](01_python_basics/python_concept_map.py)

## How to Run Lesson 1

From this repo folder, run:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" 01_python_basics\motor_safety_demo.py
```

To run the broader concept map script:

```powershell
& "$env:LOCALAPPDATA\Programs\Python\Python313\python.exe" 01_python_basics\python_concept_map.py
```

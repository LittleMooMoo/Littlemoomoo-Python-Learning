Add a photograph, drawing, or original PDF

Click where you want the image or PDF link to appear, then add a caption that explains the work. Uploading a PDF adds a link and fills in its URL, which you can also attach to an image caption.

PNG, JPEG, and WebP: up to 25 MB. PDFs: up to 80 MB. The editor records image dimensions automatically. Source documents elsewhere on your computer are not modified.

How to use this editor
  1. Choose a page or project section from the list on the left.
  2. Click in the white page to edit. Select text to change its style or add a link. Use HTML view when you need precise control over an equation or code block.
  3. Use the upload panel for photographs, CAD screenshots, and original notes. To add a section, choose its project in the left menu and select Add a project section.
  4. Choose Save & build. This saves your text, rebuilds the site, and runs its checks. If a check fails, your edits remain saved. Open Build details to see what needs fixing before you publish.
  5. Choose Preview to see the last saved build. After making a correction, save again to update the preview.
  6. In GitHub Desktop, select only changes inside Website, review them, commit, and push to main. Leave unrelated learning work unselected. The editor and its session token stay out of the public website.

Work on one section at a time. Keep original PDF links beside handwritten previews and state the assumptions behind your results. HTML view is available for direct changes to equations or layout.

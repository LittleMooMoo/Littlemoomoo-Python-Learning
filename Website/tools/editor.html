How to use this editor
  1. Select a page or an individual project section on the left.
  2. Edit directly in the white page. Highlight text to format it or add a link. Existing equations, captions, and code remain part of the HTML.
  3. Use the upload panel to add actual engineering images and links to original notes. Add a new project section from the project menu when needed.
  4. Choose Save & build. The editor rebuilds and checks the complete site. If a check fails, your text stays saved; read the message and fix the issue before publishing.
  5. Choose Preview to check the built page. Save again after any correction.
  6. Use GitHub Desktop to review, commit, and push your Website changes. This local editor and its session token are never included in the public website.

HTML view is available for precise equation or layout adjustments. Change one section at a time, keep original-note links beside previews, and retain the engineering assumptions attached to results.

Position, velocity, and feedforward torque
τ = Kp(qdes − q) + Kd(q̇des − q̇) + τff

The custom Recoil control mode combines position error, velocity error, and a feedforward torque command. The documented interface uses output-joint radians, radians per second, and newton-metres; this implementation uses its own packet format.

I checked the exported components, center of mass, inertia orientation, and coordinate frames before using the CAD model for dynamics. A model can look complete while leaving hardware out of its mass calculation.

An earlier corrected simulation snapshot has 13 links, 12 moving joints, and 12.54 kg of CAD-derived mass. That mass belongs to this CAD component snapshot; physical robot revisions need separate weight measurements.

Rotate and shift each component inertia
Itotal = Σ [RiIiRiᵀ + mi((di·di)I − didiᵀ)]

Each inertia tensor is rotated into the same frame and shifted to the overall center of mass using the parallel-axis theorem. The model uses the listed component masses without global scaling.

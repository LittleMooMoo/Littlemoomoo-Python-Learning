A CAD export can have the right shape and still omit mass-bearing components. I worked through component accounting, center of mass, inertia orientation, and frame conventions before using the model as a dynamics foundation.

An earlier corrected simulation snapshot has 13 links, 12 moving joints, and 12.54 kg of CAD-derived mass. That number describes this model and component snapshot; it is not a measured weight for every physical robot revision.

Rotate and shift each component inertia
Itotal = Σ [RiIiRiᵀ + mi((di·di)I − didiᵀ)]

Each component inertia is rotated into a common frame, then shifted to the aggregate center of mass with the parallel-axis theorem. The component masses are accounted for directly rather than scaled by a single global factor.

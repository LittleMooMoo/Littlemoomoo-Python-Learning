Start with the geometry

I began by separating the hip offset from the two-link sagittal triangle. In these early notes, I used a coordinate sketch, trigonometry, and the cosine rule to work back from a foot position to joint angles.

Geometric IK in the earlier Python convention
a = √(y² + z² − ℓh²)
r = √(x² + a²)
κ = acos[(ℓs² + ℓt² − r²) / (2ℓsℓt)]
β = acos[(ℓt² + r² − ℓs²) / (2ℓtr)]
h = π/2 − atan2(y,z) − atan2(a,ℓh)
t = β − atan2(x,a),   s = π − κ

This earlier model uses millimetres: ℓh = 84.26 mm and ℓt = ℓs = 270 mm. The code clamps square-root and acos arguments and rejects a degenerate zero-length triangle, but those checks do not reject every unreachable target.

Re-derive the leg through a transform chain

For the later derivation, I wrote out each joint rotation and link translation. The retained C++ leg convention is x forward, y right, z down, with h about −x, t about +y, and relative knee angle s about −y.

Retained C++ transform convention
T01 = Rx(−h) Ty(ℓh)
T12 = Ry(t) Tz(ℓt)
T23 = Ry(−s) Tz(ℓs)
T03 = T01T12T23

Each rotation is a proper rotation, and the translations and joint axes use the stated frames. The first three components of T03[0,0,0,1]ᵀ give the foot position.

Write the current FK and its derivative together

Compact current C++ FK
δ = s − t,   A = ℓt cos t + ℓs cos δ
x = ℓt sin t − ℓs sin δ
y = ℓh cos h + A sin h
z = A cos h − ℓh sin h

The current per-leg geometry uses ℓt = ℓs = 0.27 m and signed hip offsets ±0.07456 m. These parameters and angle conventions differ from the earlier Python model.

Analytical position Jacobian · J = ∂p / ∂[h,t,s]
J=[0A−ℓs cos δz−x sin h−ℓs sin δ sin h−y−x cos h−ℓs sin δ cos h]

Each column gives the foot-position derivative for one joint coordinate. For the hip, ∂y/∂h = z and ∂z/∂h = −y follow directly from the rotation. Entries have units m/rad.

Check the Jacobian a second way

Geometric revolute-joint column
Ji = ai × (pfoot − oi)

With the joint axis ai, joint origin oi, and foot position in the same frame, I can construct each Jacobian column from a cross product. The MATLAB study checks that these columns and the symbolic derivative ∂p/∂q are exactly equal.

Reconcile the notebook coordinates with the retained C++ model
qnotebook = [−h, t + π/2, −s]ᵀ
D = diag(−1, 1, −1)
Jretained(q) = Jnotebook(qnotebook(q)) D

I used the chain rule to map the notebook coordinates to the retained C++ convention. That mapping is separate from both the older Python convention and the physical encoder calibration.

Return from foot position to joint angles

Current C++ IK branch
a = √(y² + z² − ℓh²)
c = (x² + a² − ℓt² − ℓs²) / (2ℓtℓs)
s = acos c,   B = ℓt + ℓs cos s,   D = ℓs sin s
h = atan2(ay − ℓhz, ℓhy + az)
t = atan2(Bx + Da, Ba − Dx)

The code checks for finite inputs, hip-plane reach, cosine-rule reach, and indeterminate cases before accepting this branch. Using it on the robot also requires the physical joint reference to match.
